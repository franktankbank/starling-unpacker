> A cli to unpack starling texture atlases

### 🏠 [Homepage](https://github.com/franktankbank/starling-unpacker#readme)

## Install

```sh
npm install starling-unpacker -g
```

## Usage

```sh
starling-unpacker --atlas atlas.xml --sprite sprite.png --output ./output
```
